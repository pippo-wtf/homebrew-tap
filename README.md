# Folio for Homebrew

Install [Folio](https://github.com/pippo-wtf/folio), a beautiful Markdown app for designers and creatives.

```sh
brew install --cask pippo-wtf/tap/folio
```

Requires an Apple silicon Mac with macOS 14 or later. This preview is not yet Apple-notarized; see Folio's [installation instructions](https://github.com/pippo-wtf/folio#installation).

To update an existing Homebrew installation:

```sh
brew update
brew upgrade --cask pippo-wtf/tap/folio
```
